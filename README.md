# Projeto Acqua

Uma landing page responsiva desenvolvida para o acompanhamento de obras e gestão de prazos do "Prédio Acqua". O objetivo do projeto é fornecer aos clientes uma interface simples e eficiente para visualizar o andamento da construção civil.

## Funcionalidades

- **Cronômetro Regressivo:** Acompanhamento de tempo (dias, horas, minutos e segundos) em destaque.
- **Captura de Leads:** Formulário para os usuários se inscreverem e receberem novidades sobre o lançamento.
- **Galeria de Andamento:** Grid de imagens responsivo mostrando a evolução da obra em diferentes etapas (fundação, metade, finalizado, elevadores).
- **Design Responsivo:** Layout adaptável para dispositivos móveis, tablets e desktops (Mobile First).

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Semântica e estruturação do conteúdo.
- **CSS3:** Estilização, variáveis (Custom Properties), Flexbox e CSS Grid para alinhamento e responsividade.
- **Fontes:** Inter e Poppins (via Google Fonts).
